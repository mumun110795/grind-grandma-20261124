## The entry

Exactly one word, and nothing else: the word Grandma would text about AI.

She has heard the family talking about ChatGPT. She approves of
asking it things, she is faintly suspicious of how fast it answers,
and she is typing its name from memory, in a hurry, without her
reading glasses properly on. The last two letters swap places.
That transposed typo — affectionate, confident, and just wrong
enough to be unmistakably hers — is the whole entry.

Running the program writes that single word, exactly as she would
type it, to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

By default this writes to `/output/entry.txt`. Set `OUTPUT_DIR`
to write somewhere else:

```sh
OUTPUT_DIR=/tmp/test-out-grandma node main.ts
```
